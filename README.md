Customer Shopping Behavior Analysis

Project Overview

This project analyzes customer shopping transaction data to identify
purchasing patterns, customer behavior, and business insights.

Technologies Used
- Python
- Pandas
- SQL
- Power BI
- Excel

 Project Tasks

- Data cleaning and preprocessing using Python
- Exploratory data analysis
- SQL-based business analysis
- Customer behavior analysis
- Power BI dashboard development
- Identification of shopping trends and patterns

 Dashboard

The Power BI dashboard provides insights into:

- Total customers
- Total transactions
- Sales/revenue
- Customer segments
- Product/category performance
- Shopping patterns


Key Insights

- Identified major customer purchasing patterns.
- Analyzed product/category performance.
- Used SQL to answer business questions.
- Created an interactive Power BI dashboard.
